# Data and code availability: release status

## Code Availability

This prepared release contains source code for upstream SSB processing, regional quantification, statistical analysis and figure generation, together with version records, input specifications and data-free tests. Its local release version is 1.0.0. A public repository URL or archive DOI has not yet been assigned; none is claimed here. No open-source license has been selected by the authors.

## Data Availability

No participant-level data are distributed in this code release. Original clinical workbooks, reviewed participant lists, individual sequencing files, breakpoint BED files, source-data tables linked to participants, fitted participant objects and individual prediction scores are excluded. The public example is synthetic and is explicitly labeled as such.

Reference-genome resources and STRING annotations are third-party resources, not participant datasets generated by this repository. Their required versions and roles are documented in the input contract and provenance files; they are not relicensed here.

The authors have not supplied a public dataset accession, controlled-access repository record, designated access contact or approved access procedure for the participant data. Consequently this document does not make an unsupported “available upon request” promise. Those details must be resolved before adapting it into a final manuscript Data Availability statement.
