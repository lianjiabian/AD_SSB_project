## Minimum schemas

- Final grouping TSV: `sample_id`, `group`; unique participants; group values `HC`, `AD`, `Other` under the documented pathology definition. The clinical preparation code validates the complete cohort against the review CSV.
- Private review-check TSV: `sample_id`, `variable`, `expected`; one assertion per row, no duplicate participant-variable key. Variables refer to the prepared participant manifest. Provide actual approved values externally; synthetic examples are not accepted as study review decisions.
- Complete deduplicated BED: chromosome, zero-based start, end=start+1, identifier, score, strand. Both `+` and `-` events may be retained at the same coordinate. Failed files must not be represented as biological zeros.
- Gene matrices generated by the analysis: gene IDs as unique row keys, participant IDs as columns; raw count, SSB_LPKM and log-signal are separate outputs. Symbols are annotations.
- Missing clinical observations remain missing. Main descriptive tables use observed data; historical group-wise random imputation is not a replacement input for the final models.

The parser preserves original reviewed-column names; the public code is not permission to release the corresponding records. Before transferring clinical inputs, the study team must confirm the applicable consent, ethics and access process. This repository does not fabricate an access committee or an approval procedure.
