# Peripheral-blood SSB atlas in cognitive disease

Reproducible upstream processing, downstream statistics and manuscript visualization for the reviewed SSB cohort. This is a **code-only release**: no participant-level clinical records, group lists, raw sequencing data, BED files or fitted participant-level objects are distributed here.

## Quick start without restricted data

Requirements: R and Python 3; Bash for shell syntax checks. These tests do not need the clinical dataset or install analysis packages.

```bash
python3 tools/check_release.py
python3 tests/test_python_sources.py
Rscript tests/test_r_sources.R
Rscript 02_downstream_analysis_visualization/analysis/96_metric_unit_tests.R
Rscript examples/synthetic/run_metrics.R
```

The example prints synthetic normalization results and asserts the shared-denominator Ri identity. It is **not** a miniature patient cohort, a validation of clinical effects or a substitute for re-fitting study models.

## Reproduce the study with authorized inputs

1. Obtain authorized inputs and match the original reference/software versions; see [the input contract](docs/INPUTS.md).
2. Copy `config/local.env.example.sh` to a **location outside the repository**, edit its paths and controlled participant-specific settings, then source it.
3. Run dependency/input preflight and inspect the execution plan:

```bash
source /absolute/path/to/my-private-settings.sh
bash 02_downstream_analysis_visualization/run.sh check
bash 02_downstream_analysis_visualization/run.sh all --out=/absolute/new/ssb_reproduction
```

4. Add `--execute` only when ready to compute. The same applies to the upstream entry point. No scientific task starts by default.

```bash
bash 01_upstream_analysis/run_upstream.sh --plan
bash 01_upstream_analysis/run_upstream.sh --execute
bash 02_downstream_analysis_visualization/run.sh all --execute --out=/absolute/new/ssb_reproduction
```

Full reproduction requires restricted inputs. The public CI checks source integrity and synthetic algebra only; it does not claim to reproduce patient-derived findings. [Stage-by-stage commands and exact limitations](docs/REPRODUCIBILITY.md).

## Study-specific definitions

The fixed final cohort contains 261 participants: HC 144, author-reviewed Core 1-positive AD pathology 89, and Core 1-negative cognitive disorders 28. The complete-covariate primary cohort contains 259; the direct pathology comparison contains 117. These counts are fixed-study assertions, not defaults for arbitrary datasets. AD/Other here denote the reviewed pathology groups, not an automatic clinical probable-AD/MCI classification.

Four feature spaces are retained: GENE, EXON, INTRON and TSS200. EXON is primary, GENE is the principal sensitivity space, and INTRON/TSS200 are complementary. Gene identifiers—not symbols—are the computational keys.

`SSB_LPKM = within-gene nonredundant regional count × 10^10 / complete-library deduplicated positions`

`Ri_region = sum of regional gene counts / mean of unfiltered GENE-count totals across the final cohort`

All four Ri spaces share the same GENE denominator. No additional gene-length divisor or TPM conversion is applied to SSB_LPKM. The aggregate reference denominator is 875180.647509579 for the archived fixed inputs. [Detailed metric and coordinate definitions](docs/METHODS.md).

## Outputs and figures

Individual plots, composite plots, source-data workbooks, actual-n/statistical tables and reporting templates are generated by R. PDF/SVG retain vector elements; TIFF is exported at 600 dpi. Native editable PPT requires `rvg`. The latest Figure 4 has two rows and four columns, with 60-mm physical plotting axes in each direction; equal physical axes do not change numeric axis units.

The S18 archival revision modifies existing PDF/SVG/raster legend text; it is not an inferential rerun. Its script does not itself update PPT files. Reporting code contains archived result-language templates and must be checked against recomputed outputs before manuscript submission.

## Provenance, data access and rights

The public source derives from the frozen code bundle `SSB_reproducible_code_20261022`. Local server paths were replaced with portable examples, and participant-specific checks were externalized. Algorithms, model formulas, normalization constants and random-seed ordering were retained. `PROVENANCE.tsv` records source/public MD5s; `FILE_MANIFEST.tsv` and `SHA256SUMS.txt` describe this release.

Participant-specific adjudication checks and a prespecified discordant-record sensitivity identifier must be supplied outside GitHub. No data access approval, repository accession, manuscript DOI, author list or open-source license has been invented. See [Data and code availability](docs/DATA_AND_CODE_AVAILABILITY.md), [citation guidance](CITATION.md) and [license status](LICENSE_STATUS.md).

Research foundations: [2019 SSB profiling study](https://doi.org/10.1038/s41467-019-13602-7) and [2024 Aging Cell study](https://doi.org/10.1111/acel.14122). This repository implements the explicitly documented metric choices for the present application; it does not imply that every historic label or formula was identical across studies.
